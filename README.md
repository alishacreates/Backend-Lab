## 🎯 Course Outcomes

The course aims to develop the ability to:

* **CO1:** Understand Back End Development Fundamentals

## 🚀 Running the Repository

Clone the repository:

```bash id="0u76k8"
git clone https://github.com/alishacreates/Backend-Lab.git
```

Navigate to the repository:

```bash id="csgofv"
cd Backend-Lab
```

Open it in Visual Studio Code:

```bash id="yhdh0u"
code .
```

For Node.js labs, navigate to the respective lab directory and install its dependencies:

```bash id="vwy7h2"
npm install
```

Then run the application according to the scripts defined for that lab.
